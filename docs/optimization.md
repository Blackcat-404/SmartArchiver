# Оптимізація SmartArchiver — Учасник 3

## Пристосованість

Пошук оцінює не кількість токенів, а повний тракт SmartArchiver:

`аналіз → блоки → LZ77 → Гаффман → пакування томів → AES-256-CTR → HMAC → розпакування`.

Для кожної хромосоми вимірюються:

```text
S = B_orig / (B_orig + B_arc)
T = t_ref / (t_ref + t)
Q = α·S + β·T
```

Якщо round-trip не відновив усі файли, `Q = 0`. Значення `S` і `T` зберігаються окремо, тому з тих самих рядків можна побудувати фронт Парето.

## Хромосоми

Базова хромосома має три гени:

| Ген | Значення |
| --- | --- |
| `window` | вікно пошуку LZ77, 256 Б–32 КіБ у форматі, у базовому просторі сітка 256 Б–32 КіБ |
| `min_match` | мінімальна довжина збігу, 3–258 |
| `abandon_threshold` | мінімальна частка економії, необхідна для збереження стисненого блока; `0.05` означає 5% |

Повна хромосома додає `search_depth`, `huffman_block_size`, `history_k`, `perceptron_architecture` і `strategy_flags`.

Прапорці повного пошуку: класифікатор, передбачення байта, стратегія по блоках, DP/iterative parser, DP-пакування та дозвіл raw-блоків. Передбачення в експертному режимі навчає детерміновану модель для обраного `k` і архітектури, кодує залишки, а після розпакування декодує їх назад і перевіряє оригінал.

Для трьох генів використано рівномірний кросовер; для повної хромосоми — двоточковий кросовер по восьми генах. Мутація адаптивно зменшується протягом поколінь і підсилюється після застою. Еліти входять у наступне покоління, а їхнє повторне оцінювання залишається в чесному бюджеті.

## Чесні порівняння

GA оцінює початкову популяцію і кожне наступне покоління однаковим розміром. Еліти повторно проходять оцінювач, тому їхні обчислення входять до бюджету. Випадковий пошук працює пакетами того самого розміру й має точно таку саму кількість викликів fitness. Елітизм зберігає найкраще значення, тому для D1 №17 перевіряється:

```text
best(last_generation) >= best(generation_0)
```

## Команди

```bash
dotnet run --project src/SmartArchiver.Cli -- genetic-experiment Datasets
dotnet run --project src/SmartArchiver.Cli -- genetic-experiment Datasets team_config.json full
dotnet run --project src/SmartArchiver.Cli -- export-ga <experiment-id> docs/ga/ga-vs-random.csv
```

Команда зберігає кожну оцінену хромосому в `GeneticIndividuals`. Експертний режим додатково запускає локальний пошук і друкує недоміновані точки фронту Парето за `S` та `T`.
