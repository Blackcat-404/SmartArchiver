# Datasets — навчальний корпус для SmartArchiver

Папки `0`–`6` відповідають значенням `file_type`, використаним в експерименті.

| Група | Вміст |
| --- | --- |
| `0` | Синтетичні текстові файли UTF-8 |
| `1` | Синтетичні приклади вихідного коду C#, Python, C++ |
| `2` | Синтетичні структуровані дані JSON, CSV, XML |
| `3` | Справжні растрові BMP, без стиснення |
| `4` | **Імітація** двійкових виконуваних файлів (`.bin`), не справжні `.exe` / `.dll` |
| `5` | Справжні ZIP, PNG і zlib-стиснені байти |
| `6` | Синтетичні послідовності: повторення, шаблон, випадкові, змішані |

## Як запускати

1. Розпакуйте теку `Datasets` у корінь репозиторію поруч із `src` та `tests`.
2. Із кореня запустіть `dotnet run --project src/SmartArchiver.Cli`, виберіть **7 → 1** та залиште каталог `Datasets`.
3. Наявність файлів усіх груп не означає репрезентативності набору.
